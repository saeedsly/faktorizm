# بسته نصب فاکتوریزم

هر دو بسته از همین شاخه قابل دانلود است. آرشیوها کامل و آزمون‌شده‌اند (تست نفوذ ۲۴/۲۴، تست بار ۳۰۰۰ کاربر، اسموک ۸/۸).

## ۱) نسخه کامل ویندوز — Node + MySQL + OCR قوی

**فایل:** `faktorizm-xampp.zip` (۴۰ مگابایت)
**دانلود:** https://github.com/saeedsly/faktorizm/raw/arena/b3a2f281-faktorizm/downloads/faktorizm-xampp.zip

مناسب ویندوز ۱۰ و ۱۱ (۶۴ بیتی). شامل سرور Node، رابط کاربری آماده، پایگاه داده MariaDB و سرویس OCR آفلاین PP-OCRv5.

**نصب:**
1. زیپ را Extract کنید (مسیر بدون فاصله و بدون حروف فارسی).
2. XAMPP را باز کنید و MySQL را روشن کنید.
3. `setup.bat` را اجرا کنید و منتظر پیام پایان بمانید.
4. `start.bat` را اجرا کنید.
5. مرورگر: `http://localhost:8787` — ورود اولیه: `admin@faktorizm.ir` / `Admin@1405`

پایتون ۳.۱۱ (۶۴ بیتی) اختیاری اما توصیه‌شده است؛ `setup.bat` آن را خودکار تشخیص می‌دهد، محیط مجازی می‌سازد و سرویس OCR را نصب می‌کند. اگر پایتون نصب نباشد، برنامه بدون خطا بالا می‌آید و از موتور داخلی مرورگر استفاده می‌کند.

برای نصب کاملاً آفلاین (بدون اینترنت روی سیستم مقصد)، پوشه `ocr-service/wheels` را از مخزن کنار پوشه `ocr-service` قرار دهید؛ `setup.bat` خودش از همان چرخ‌ها نصب می‌کند.

### سه حالت خوانش

از صفحه «تنظیمات» بخش OCR:

- **آفلاین و محلی** (پیش‌فرض): هیچ داده‌ای از دستگاه بیرون نمی‌رود؛ موتور PP-OCRv5 روی همان رایانه کار می‌کند.
- **ترکیبی**: خوانش محلی + سرویس ابری، سپس مقایسه و انتخاب بهترین مقدار هر فیلد. بالاترین دقت را می‌دهد و نیازمند کلید API خودتان است (Gemini یا OpenAI). کلید فقط روی همان دستگاه ذخیره می‌شود و پیش از ارسال هر سند اجازه می‌گیرد.
- **فقط ابری**: سریع‌ترین خوانش ساخت‌یافته، نیازمند اینترنت.

**چطور موتور قوی را تست کنید:** یک عکس فاکتور واقعی را در بخش اسکن بارگذاری کنید. در صفحه «تنظیمات» نشان موتور فعال را ببینید؛ عبارت «PP-OCRv5 محلی» یعنی موتور قوی در حال کار است و «Tesseract» یعنی سرویس پایتون بالا نیامده و موتور پشتیبان فعال شده است.

## ۲) نسخه سبک استاتیک — ویندوز ۷، بدون Node

**فایل:** `faktorizm-htdocs.zip` (۲۸ مگابایت)
**دانلود:** https://github.com/saeedsly/faktorizm/raw/arena/b3a2f281-faktorizm/downloads/faktorizm-htdocs.zip

فقط مرورگر لازم است؛ داده‌ها در IndexedDB همان دستگاه می‌مانند و هیچ پیش‌نیاز سروری ندارد.

**نصب:**
1. محتوای زیپ (پوشه `faktorizm`) را در مسیر `C:\xampp\htdocs\` کپی کنید.
2. XAMPP را باز کنید و Apache را روشن کنید (MySQL لازم نیست).
3. مرورگر: `http://localhost/faktorizm/`

در این نسخه موتور OCR همان Tesseract درون‌مرورگر است و سرویس پایتون ندارد.
