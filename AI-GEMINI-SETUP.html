  1. صفحه کلید را باز کن

    در مرورگر برو به https://aistudio.google.com/apikey. اگر باز نشد، aistudio.google.com را باز کن و از منوی سمت چپ Get API key را بزن.

  2. با حساب گوگل وارد شو

    اگر اولین بار است، صفحه شرایط استفاده می‌آید؛ تیک پذیرش را بزن و ادامه بده.

  3. Create API key را بزن

    پنجره‌ای باز می‌شود و می‌پرسد کلید در کدام پروژه ساخته شود. گزینه Create API key in new project را انتخاب کن (ساده‌ترین راه).

  4. کلید را کپی کن

    کلید با AIza شروع می‌شود و حدود ۳۹ نویسه است. روی آیکن کپی بزن و همان لحظه در جای امنی نگه دار.

    AIzaSyD-1a2b3c4d5e6f7g8h9i0jKLMNOPQRST

  6. یک فاکتور واقعی بخوان

    صفحه اسکن ← عکس فاکتور را بینداز ← ارسال کن و بخوان. اولین بار یک پنجره تأیید می‌آید که نام فایل، سرویس و مدل را نشان می‌دهد. بعد از خوانش، در صفحه ویرایش سند زبانه «اقلام و متن OCR» را ببین.

۵ اگر منطقه‌ات پشتیبانی نشود

گوگل AI Studio برای برخی کشورها (از جمله ایران) به دلایل قانونی باز نمی‌شود. استفاده از VPN برای دور زدن این محدودیت خلاف قوانین گوگل است و می‌تواند به تعلیق کلید و حساب منجر شود؛ توصیه نمی‌کنم.

گزینه الف — مدل محلی روی همین رایانه (بدون ثبت‌نام، بی‌نهایت)

هیچ حسابی لازم نیست و هیچ محدودیتی هم ندارد؛ فقط مدل را یک بار دانلود می‌کنی:

winget install Ollama.Ollama
ollama pull qwen2.5vl:7b

سپس در تنظیمات: سرویس «مدل محلی روی رایانه خودتان (Ollama)» ← آدرس پایه http://localhost:11434/v1 ← مدل qwen2.5vl:7b ← آزمون اتصال. کلید نمی‌خواهد.

نیازمندی: حدود ۸ گیگابایت رم آزاد. با کارت گرافیک، سرعت چند برابر می‌شود.

۶ امنیت کلید

  • کلید مثل رمز عبور است؛ در چت، اسکرین‌شات یا فایل عمومی نگذارش.
  • کلید فقط در پایگاه داده همین دستگاه (IndexedDB) ذخیره می‌شود.
  • در فایل پشتیبان JSON صادر نمی‌شود؛ اگر پشتیبان را جایی ببری، کلید همراهش نمی‌رود.
  • اگر شک کردی لو رفته: در AI Studio کلید را Delete کن و کلید تازه بساز.
  • برنامه پیش از هر ارسال، نام فایل و سرویس و مدل را نشان می‌دهد و تصویر را ذخیره نمی‌کند.
