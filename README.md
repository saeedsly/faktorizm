# فاکتوریزم — سامانه هوشمند اسکن، مدیریت و فروش اشتراکی فاکتور

محصولی کامل برای پایان دادن به ورود دستی فاکتورها: عکس، اسکن یا PDF فاکتور و رسید حرارتی را بگیرید؛
موتور بینایی ماشین به‌صورت آفلاین متن را می‌خواند و فیلدهای سند را استخراج می‌کند. نسخه دوم محصول،
یک پلتفرم چندسازمانی کامل است: حساب کاربری امن، نقش و دسترسی، اشتراک و لایسنس، تیکت پشتیبانی،
دیتابیس MySQL و REST API آماده اتصال به نرم‌افزار حسابداری.

> طراحی و توسعه توسط **سعید سالاری** — تمامی حقوق این محصول محفوظ است.

## معماری کلی

| لایه | فناوری |
| --- | --- |
| رابط کاربری | React 19، TypeScript، Vite، Tailwind CSS، فونت وزیرمتن، RTL کامل |
| داده لوکال | Dexie روی IndexedDB (کار آفلاین و حریم خصوصی اسناد) |
| بینایی ماشین | Tesseract.js 7 با هسته WASM و داده فارسی/انگلیسی داخل پروژه، pdf.js، پیش‌پردازش Otsu |
| سرور | Node.js + Express 5، اعتبارسنجی Zod، هلمت امنیتی، Rate Limit |
| پایگاه داده | MySQL 8 (InnoDB، utf8mb4 فارسی) با Connection Pool؛ درایور حافظه برای توسعه و تست |
| احراز هویت | JWT کوتاه‌مدت + Refresh Token چرخشی، bcrypt، TOTP دو عاملی |
| تجاری‌سازی | کد اشتراک هش‌شده، پلن ماهانه/فصلی/سالانه، قفل خودکار پس از انقضا |

## شروع به کار

```bash
npm install        # دارایی‌های OCR هنگام نصب در public/vendor کپی می‌شوند
npm run dev        # رابط کاربری روی http://localhost:5173
npm run server     # API نسخه ۲ روی http://localhost:8787 (درایور حافظه به‌صورت پیش‌فرض)
```

پس از اجرا، اولین ثبت‌نام‌کننده «مالک سازمان» می‌شود و چهارده روز اشتراک آزمایشی می‌گیرد.
پنج کد اشتراک نمونه هنگام اولین اجرا در لاگ سرور چاپ می‌شوند.

## استقرار با MySQL

### الف) Docker (توصیه‌شده)

```bash
cp .env.example .env   # مقادیر JWT_SECRET و رمزها را حتما عوض کنید
docker compose up -d --build
```

این دستور یک MySQL 8 با اسکیمای آماده و خود سرور API را بالا می‌آورد. رابط کاربری را با
`npm run build` بسازید و پوشه `dist` را روی وب‌سرور (Nginx) سرو کنید؛ درخواست‌های `/api` را
به کانتینر API پراکسی کنید.

### ب) نصب دستی

```sql
-- روی سرور MySQL
CREATE DATABASE faktorizm CHARACTER SET utf8mb4 COLLATE utf8mb4_persian_ci;
SOURCE server/src/db/schema.sql;
```

```bash
DB_DRIVER=mysql \
MYSQL_HOST=127.0.0.1 MYSQL_USER=faktorizm MYSQL_PASSWORD=... MYSQL_DATABASE=faktorizm \
JWT_SECRET=$(openssl rand -hex 48) \
NODE_ENV=production node server/src/index.js
```

لایه دسترسی داده با الگوی Repository طوری نوشته شده که فقط با عوض کردن `DB_DRIVER` بین
MySQL و درایور حافظه جابه‌جا می‌شوید؛ هر دو دقیقا یک قرارداد دارند و همه کوئری‌های MySQL
پارامتریزه هستند.

## مدل امنیتی

- **رمز عبور:** فقط هش bcrypt (هزینه ۱۲ در تولید) ذخیره می‌شود؛ سیاست پیچیدگی رمز اجباری است.
- **توکن:** Access Token عمر ۱۵ دقیقه‌ای با HS256؛ Refresh Token هش‌شده در دیتابیس با چرخش
  در هر استفاده و ابطال خودکار کل خانواده توکن هنگام تشخیص بازاستفاده.
- **دو عاملی:** TOTP سازگار با Google/Microsoft Authenticator.
- **قفل حساب:** پنج ورود ناموفق پشت سر هم، حساب را ۱۵ دقیقه قفل می‌کند.
- **کنترل دسترسی:** پنج نقش (مالک، مدیر، حسابدار، اپراتور، مشاهده‌گر) و مجوز عملیاتی روی هر اندپوینت.
- **چندسازمانی:** هر رکورد به `workspace_id` مقید است و بررسی مالکیت در هر درخواست انجام می‌شود (ضد IDOR).
- **هاردنینگ:** Helmet/CSP، CORS با فهرست مجاز، سقف حجم بدنه، Rate Limit و حذف هدرهای شناسایی سرور.
- **ممیزی:** ورودها، تغییر کاربران، لایسنس و تیکت‌ها با IP در `audit_logs` ثبت می‌شوند.

## سیستم اشتراک

کد اشتراک با قالب `FKM-XXXX-XXXX-XXXX-XXXX` و الفبای بدون ابهام تولید و فقط به‌صورت هش SHA-256
در دیتابیس ذخیره می‌شود. مالک سامانه از صفحه «اشتراک و لایسنس» کد را دسته‌ای می‌سازد و خروجی CSV
می‌گیرد. مشتری کد را وارد می‌کند؛ مدت اعشار به انقضای فعلی اضافه شده و پس از انقضا، فقط بخش‌های
کاری قفل می‌شوند (دسترسی به تمدید، تیکت و امنیت باز می‌ماند) و هیچ داده‌ای حذف نمی‌شود.

## تست‌ها

```bash
npm test             # پارسر فارسی، خروجی اکسل، سلامت OCR و تست دود رابط
npm run test:pentest # ۲۰ بردار حمله واقعی: JWT جعلی، SQLi، IDOR، RBAC، قفل حساب، XSS، CORS…
npm run test:load    # شبیه‌سازی ۳۰۰۰ کاربر همزمان (۱۵ هزار درخواست) و سنجش p95/p99
```

گزارش آخرین اجرا: تست نفوذ **۲۰/۲۰ دفع موفق** و تست بار **۳۰۰۰/۳۰۰۰ کاربر موفق** با سرور پایدار.
