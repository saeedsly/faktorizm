# فاکتوریزم — سامانه هوشمند اسکن و مدیریت فاکتور

وب‌اپلیکیشن فارسی و راست‌چین برای پایان دادن به ورود دستی فاکتورها: عکس، اسکن یا PDF فاکتور
(حتی رسیدهای حرارتی) را بگیرید؛ موتور بینایی ماشین به‌صورت **کاملاً آفلاین** متن را می‌خواند،
شماره فاکتور، تاریخ شمسی، طرف حساب، اقلام، تخفیف، مالیات و مبلغ کل را استخراج می‌کند و آماده
**خروجی اکسل** یا اتصال از طریق **REST API** به نرم‌افزار حسابداری می‌شود.

> هیچ سندی از دستگاه شما خارج نمی‌شود. OCR روی WASM داخل مرورگر اجرا می‌شود و داده‌ها در IndexedDB لوکال ذخیره می‌گردند.

## ✨ چرا فاکتوریزم؟

- 🧠 **OCR آفلاین فارسی + انگلیسی** با موتور Tesseract.js (هسته WASM و داده زبان داخل پروژه)
- 🧾 استخراج هوشمند فیلدهای فاکتور فارسی با امتیاز اطمینان برای هر فیلد
- 📄 پشتیبانی PDF چندصفحه‌ای، تصویر JPG/PNG/WEBP و اسکن مستقیم با دوربین
- 📊 پردازش گروهی با صف و نوار پیشرفت زنده
- 📈 داشبورد و گزارش مالیات بر ارزش افزوده روی تقویم شمسی
- 🗂️ دفتر طرفین حساب و کالا/خدمات با تکمیل خودکار
- 📤 خروجی Excel چند‌شیتی، CSV، چاپ/PDF و قالب آماده سپیدار، همکاران سیستم، رایورز و پارسیان
- 🔑 مرکز API با کلید اختصاصی، کنسول تست زنده، OpenAPI و وب‌هوک
- 🎨 رابط حرفه‌ای RTL با فونت وزیرمتن، تم تیره/روشن، انیمیشن و میانبر کیبورد
- 🔢 ارقام فارسی، تقویم جلالی و ۶۰ ویژگی کامل (فهرست داخل اپ: صفحه «۶۰ ویژگی»)

## 🧱 معماری و تکنولوژی

| لایه | فناوری |
| --- | --- |
| رابط کاربری | React 19، TypeScript، Vite 8، Tailwind CSS 4 |
| حالت و داده | Zustand، Dexie (IndexedDB)، dexie-react-hooks |

## 🚀 شروع به کار

```bash
npm install      # دارایی‌های OCR هنگام نصب به public/vendor کپی می‌شوند
npm run dev      # اجرای سرور توسعه روی http://localhost:5173
```

ساخت نسخه نهایی:

```bash
npm run build    # تایپ‌چک + بیلد production در پوشه dist
npm run preview  # پیش‌نمایش بیلد نهایی
```

سرور مرجع API (اختیاری، برای اتصال سرویس بیرونی):

```bash
npm run server   # اجرا روی پورت 8787 با ذخیره‌سازی JSON در data/db.json
```

## 🧠 خط لوله OCR

1. فایل (تصویر/PDF) یا عکس دوربین دریافت می‌شود.
2. PDF با pdf.js به تصویر صفحه‌ها تبدیل و جهت EXIF اصلاح می‌گردد.
3. پیش‌پردازش: مقیاس خاکستری، افزایش کنتراست، آستانه Otsu و بزرگ‌سازی اسناد کم‌کیفیت.
4. Tesseract.js با داده `fas+eng` (قابل تنظیم) متن را استخراج می‌کند.
5. پارسر فارسی شماره، تاریخ (شمسی/میلادی/نام ماه)، فروشنده/خریدار، ردیف اقلام،
   تخفیف، مالیات و مبلغ قابل پرداخت را با امتیاز اطمینان استخراج می‌کند.
6. فاکتور ذخیره می‌شود؛ طرف حساب و کالاهای جدید به‌صورت خودکار به دفترها اضافه می‌گردند.
7. فیلدهای کم‌اطمینان در صفحه بازبینی با نشانگر هشدار مشخص می‌شوند.

دارایی‌های موتور در `public/vendor/tesseract/` قرار دارند و اسکریپت
`scripts/copy-ocr-assets.mjs` هنگام `npm install` آن‌ها را بازتولید می‌کند.

## 📤 خروجی و قالب‌های حسابداری

- **اکسل استاندارد**: سه شیتی «فاکتورها»، «اقلام»، «خلاصه» با ستون فارسی و نمای RTL
- **قالب تخصصی**: سپیدار سیستم، همکاران سیستم (بدهکار/بستانکار ریالی)، رایورز، پارسیان (لاتین)
- **CSV** با BOM برای سازگاری با همه نرم‌زارهای جدولی
- **چاپ / PDF**: فاکتور رسمی با سربرگ کسب‌وکار از طریق پنجره چاپ مرورگر
- **پشتیبان JSON**: خروجی کامل و بازیابی همه داده‌ها از صفحه تنظیمات

## 🔌 REST API

احراز هویت با هدر `x-api-key`. کلیدها از صفحه «مرکز API» داخل اپ ساخته می‌شوند
و سرور مرجع Node همان قرارداد را روی داده فایل پیاده می‌کند.

| متد | مسیر | شرح |
| --- | --- | --- |
| GET | `/api/v1/ping` | بررسی زنده بودن (بدون احراز) |
| GET | `/api/v1/invoices` | فهرست فاکتورها (`page, limit, status, q`) |
| POST | `/api/v1/invoices` | ایجاد فاکتور (محاسبه مالیات و جمع خودکار) |
| GET | `/api/v1/invoices/:id` | دریافت یک فاکتور |
| PUT | `/api/v1/invoices/:id` | به‌روزرسانی فاکتور |
| DELETE | `/api/v1/invoices/:id` | حذف فاکتور |
| POST | `/api/v1/invoices/:id/approve` | تایید فاکتور |
| GET/POST | `/api/v1/contacts` | فهرست/ثبت طرف حساب |
| GET | `/api/v1/products` | فهرست کالا و خدمات |
| GET | `/api/v1/stats` | آمار کلیدی |

نمونه درخواست:

```bash
curl -H "x-api-key: fk_live_xxxx" \
  "http://localhost:8787/api/v1/invoices?status=review"
```

فایل استاندارد **OpenAPI 3.1** از مرکز API قابل دانلود است و کنسول تست زنده،
درخواست‌ها را روی همین دیتابیس محلی اجرا و پاسخ JSON را نمایش می‌دهد.

## 📁 ساختار پروژه

```
src/
├── components/      # کامپوننت‌های UI، چیدمان، دوربین، دیالوگ‌ها
├── hooks/           # صف پردازش OCR
├── lib/
│   ├── ocr/         # موتور Tesseract، پیش‌پردازش، pdf.js، پارسر فارسی
│   ├── exporters/   # اکسل، CSV، چاپ/PDF، پشتیبان
│   ├── api/         # موتور REST داخلی، OpenAPI، وب‌هوک
│   ├── db.ts        # طرح دیتابیس Dexie
│   ├── seed.ts      # داده نمونه
│   └── features.ts  # فهرست ۶۰ ویژگی
├── pages/           # داشبورد، اسکن، فاکتورها، گزارش، API، تنظیمات و…
server/              # سرور مرجع REST بدون وابستگی خارجی
scripts/             # تست‌ها و اسکریپت آماده‌سازی دارایی OCR
public/vendor/       # هسته WASM و داده زبان Tesseract (آفلاین)
```

## 🔒 حریم خصوصی

تمام پردازش‌ها سمت کلاینت است. کلید API، اسناد و متن OCR فقط روی همین مرورگر ذخیره می‌شوند
و هیچ تماسی با سرویس شخص ثالث وجود ندارد. برای مهاجرت بین دستگاه‌ها از «پشتیبان JSON» استفاده کنید.
